# 🏢 Sistema de Gestão de Condomínio

Projeto desenvolvido para auxiliar na administração de condomínios, permitindo o gerenciamento de moradores, funcionários, reservas de áreas comuns, encomendas, comunicados e enquetes.

## 📋 Funcionalidades

### 👥 Gestão de Moradores
- Cadastro de moradores
- Edição e exclusão de registros
- Pesquisa por nome
- Armazenamento em LocalStorage

### 👨‍💼 Gestão de Funcionários
- Cadastro de funcionários
- Consulta e atualização de dados
- Controle administrativo

### 🏠 Reserva de Áreas Comuns
- Reserva de espaços do condomínio
- Seleção de faixas de horário disponíveis
- Controle de conflitos de reserva

### 📦 Controle de Encomendas
- Registro de encomendas recebidas
- Consulta por morador
- Histórico de entregas

### 📢 Comunicados
- Criação e visualização de avisos
- Central de informações aos moradores

### 📊 Enquetes
- Perguntas de múltipla escolha
- Perguntas de alternativa única
- Campo para comentários
- Registro de votos

### 📈 Dashboard Administrativo
Indicadores em tempo real:
- Total de moradores
- Total de funcionários
- Total de reservas
- Total de encomendas
- Total de enquetes

### 👤 Perfil do Morador
- Dados pessoais
- Informações da unidade
- Contatos
